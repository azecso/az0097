## 3. تقرير Phase 0

### المنجز
- مراجعة SRS: **13 تعارضاً/ثغرة محاسبية** (C-1..C-13) و**10 فجوات تقنية** (G-1..G-10)، و16 قراراً مطلوباً (D-01..D-16).
- ADR (9 قرارات): التقنية، الاستضافة، الدفتر، FIFO، التدقيق، العزل، المصادقة، الأوفلاين، هيكل المستودع.
- التصميم المحاسبي: دليل حسابات، قوالب قيود لكل عملية، FIFO، الصرف، التحصيل الجزئي، خوارزمية تسوية الأرباح، تعريفات المقاييس، الأرصدة الافتتاحية.
- قاعدة البيانات: ERD + `schema.sql` (59 جدولاً) **مشغّل على PostgreSQL 16 بنجاح**.
- اختبارات تنفيذية للثوابت: **29/29 ناجح** (الدفتر المتوازن، عدم تعديل المرحّل، FIFO 1,600,000/600,000، منع سالب المخزون، صلاحيات رأس المال، منع تكرار الربح والدفعة، idempotency المزامنة).
- واجهات عربية RTL (خريطة صفحات + Wireframes)، مصفوفة صلاحيات، خطة PWA والمزامنة.
- مصفوفة اختبارات (TC-01..TC-11 بأرقام متوقعة محسوبة) ومعايير قبول لكل مرحلة.

### المتبقي (لا يخص Phase 0)
كل المراحل 1–6. **لا يوجد كود إنتاجي بعد** وهذا مقصود بحسب SRS §10.

### حدود صريحة / ما لم يُتحقَّق منه
- أسعار الاستضافة: **لم أذكر أي سعر** (لا أملك أسعاراً حالية موثوقة)؛ المقارنة بالمعايير فقط، والأسعار تُجمع عند اختيار المزود.
- تقديرات موارد VPS (2 vCPU / 2–4GB / 40GB) تقدير هندسي يُقاس فعلياً في Phase 6.
- المقارنة بين Next.js وLaravel أوزانها تقدير مهني، والفارق صغير؛ البديل مقبول (ADR-001).
- المخطط مسودة تصميم: لم تُكتب بعد جداول التحويل الداخلي كمستند، وبعض سطور المرتجعات، ولا seed للحسابات (انظر `04` §5).
- فقرة SRS 12 انتهت بكلمة «يجب» ناقصة.
- التحقق من RLS، وسلوك التزامن تحت الحمل، والـ API، والواجهة: لا يمكن قبل Phase 1–2.
