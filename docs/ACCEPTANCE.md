## §10 مراحل التنفيذ
Phase 0–7 منجزة بالتقارير: `docs/phase-0` … `docs/phase-7` (7: التقارير التفصيلية، الإنشاء السريع، سجل إرجاع رأس المال).

## ما لا يزال مطلوباً قبل الإنتاج (بالأولوية)
1. **Staging حقيقي** على VPS: بناء صورة Docker، `docker compose up`، PDF بالصورة، cron للنسخ، وجهة النسخ السحابية.
2. **تشغيل CI على GitHub** (لم يُشغَّل بعد).
3. قرارك على بنود 🟡/❌ أعلاه (سند استلام مستقل؟ صناديق إضافية؟ تقارير الركود؟ إشعارات بريد؟).
4. **اعتمادك** بعد تجربة Staging.
