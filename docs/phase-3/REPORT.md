# تقرير Phase 3 — المبيعات والذمم والتحصيل

> بتفويض المالك بالمتابعة دون توقف للاعتماد؛ هذا التقرير للتوثيق والمراجعة.

## ما أُنجز
- **عروض الأسعار:** مسودة ← إصدار (رقم QT، ثم يُجمَّد محتواها بـ Trigger) ← مقبول/مرفوض ← تحويل إلى فاتورة (مسودة).
- **فواتير البيع:** نقدي/آجل، دينار/دولار بسعر مثبّت، خصم بند وخصم فاتورة (4150)، شروط وملاحظات، تاريخ بيع فعلي لما يُسجَّل لاحقاً، حد ائتماني للعميل.
- **سند التسليم:** تسليم مع الفاتورة (تلقائي) أو منفصل. ترحيل السند = خروج FIFO + تكلفة البضاعة المباعة بتكلفة الطبقات الحقيقية. الإيراد عند الفاتورة والتكلفة عند التسليم (القرار D-04). رفض التسليم الزائد عن المفوتر.
- **سندات القبض:** تخصيص على فواتير، قبض جزئي، قبض زائد = رصيد دائن للعميل (2400)، استخدام الرصيد الدائن لفاتورة أخرى، **فرق صرف محقق** (7100) عند اختلاف سعر القبض عن الفاتورة.
- **عهدة الشريك:** القبض بيد الشريك يُسجَّل في حساب العهدة (1150) **مرة واحدة**؛ تسليمه للصندوق **سند تحويل** لا إيراد ولا تحصيل مضاعف. عهدة الشريك لا تُحتسب ضمن النقد المتاح.
- **مرتجعات العميل:** يعود المخزون **إلى نفس الطبقات بنفس التكلفة**، ويُعكس COGS، وتُسوّى القيمة: أولاً من المتبقي على العميل، والفائض رصيد دائن أو استرداد نقدي. عكس المرتجع يسحب المخزون من جديد.
- **عكس الفاتورة:** قيد معاكس + إرجاع المخزون + عكس القبض التلقائي للبيع النقدي، ويُمنع إن وُجدت مرتجعات أو سندات قبض مخصصة.
- **التقارير:** كشف عميل برصيد تراكمي، أعمار الديون (current/1-30/31-60/61-90/90+)، وفي كل فاتورة: إجمالي الربح وربح التحصيل (مؤشر).
- **الربح المرتبط بالتحصيل** = الربح المعدّل × MIN(1, صافي المحصّل ÷ صافي القيمة المعدّلة)، ويعالج الصفر والمرتجعات والاسترداد (لبنة Phase 4 لتسوية الأرباح).

## تصحيح لوثيقة Phase 0 (اكتشفه الاختبار)
مثال TC-07a كان خاطئاً: الربح المعدّل = (1,000,000 − 300,000) − (700,000 − 210,000) = **210,000** (لا 490,000)، والمرتبط بالتحصيل = 210,000 × 400/700 = **120,000** (لا 280,000). صُحِّحت الوثائق والاختبار.
